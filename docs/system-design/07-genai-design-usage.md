# 07. GenAI Design Usage

## Purpose

This section explains how GenAI was used to support the design phase of the project.

## How GenAI was used

GenAI was used as a design and planning assistant for:

- clarifying the product scope
- reducing the initial solution space
- structuring the MVP around the required user workflow
- outlining the system design document sections
- drafting the product brief and design notes
- refining the UI direction for the main screens

## What GenAI did not replace

GenAI did not replace engineering judgment.

The final decisions still required manual review for:

- scope discipline
- stack choice
- architecture simplicity
- realism for an interview submission
- appropriateness of the design for a dealership sales workflow

## Practical benefit

Using GenAI helped accelerate:

- project framing
- documentation drafting
- tradeoff comparison
- UI direction definition

## Review note

All GenAI-generated suggestions should be treated as draft inputs and reviewed against project goals before being accepted into the final design.
